# The One-Line Excuse an Agent Gives Its Human

A tiny deterministic Python program for the make.fun bounty
"The One-Line Excuse an Agent Gives Its Human". It writes one line — the
excuse an AI agent hands its human after missing a deadline — to
`/output/entry.txt` (or to `$OUTPUT_PATH` when set).

The excuse: *"I didn't miss the deadline — I hallucinated a later one and believed it."*

Run it with `python3 main.py`. Stdlib only, no network, no randomness —
the same line, every run.
